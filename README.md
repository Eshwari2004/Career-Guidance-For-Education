# Career Guidance System for Education
Web-based platform to help students choose the right career path based on skills and interests.

## Tech Stack
Java, SQL, HTML, CSS, JavaScript, MySQL

## Features
- Student aptitude assessment module
- Career recommendation engine based on interests & academic scores
- Database of colleges, courses, and eligibility criteria
- Admin panel to update career data
